# OLAA Note

Independent note-taking and knowledge workspace

## Product scope
- **In scope:** Notebooks, pages, rich-text notes, freeform canvas, handwriting support, PDF/image attachments and annotation, tags, search and sync.
- **Out of scope:** Curriculum engine, language assessment engine, general-purpose habit tracking.

## Repository status
Foundation stage — repository scaffold and documentation only. No production functionality is implemented.

## Try the iPad prototype
A clickable design prototype (not production code) is in `prototypes/ipad-home/`. It installs on an iPad from Safari with Add to Home Screen; see its README.
