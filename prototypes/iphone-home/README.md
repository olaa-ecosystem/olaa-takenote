# Olaa Notes: iPhone prototype

The iPhone build of the Olaa Notes prototype. It runs the same app as [`../ipad-home/`](../ipad-home/README.md) (features, limits, security and install steps are the same) with an iPhone layout. Everything in this folder except this README is generated by `tools/build.py`; see [`../README.md`](../README.md) for how to change it.

## What is different on iPhone

| Area | iPhone |
|---|---|
| Drawing | One finger draws (there is no Apple Pencil). Two fingers move, zoom and rotate the page. **Finger** in the toolbar switches one finger back to scrolling. |
| Note | Fills the screen between the top bar and the pen toolbar. No window buttons, grip or resize corner; the note cannot be moved. |
| Top bar | Full width, icons only: mood, New note, Import, Files, Delete, language, light or dark. Split screen, the date and the app shortcuts are left out. |
| Files | Not on the desk. **Files** shows them in a grid; a file or folder opens the full width of the phone with only a close button. |
| Pen toolbar | Fixed at the bottom, 86% of the iPad size, scrolls sideways; **Recent** stays at its right end. |
| Icons | File and folder icons at 80% (iPad: 90%). |
| Install | Portrait only. Same steps as on iPad: Safari → Share → Add to Home Screen. |


Tested in Chromium at iPhone 15 size with touch (`tests/iphone.spec.mjs`). Not yet tried on a real iPhone in Safari.
